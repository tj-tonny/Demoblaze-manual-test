# 🧪 Manual Testing – DemoBlaze

## 📌 Project Overview

This project focuses on **Manual Software Testing** of the [DemoBlaze](https://www.demoblaze.com/) e-commerce website. The testing was performed using **Exploratory Testing** techniques to identify functional, UI, usability, and validation issues across key application modules.

The project includes both **Positive and Negative Test Cases** to verify expected and unexpected user behaviors.

## 🎯 Testing Objectives

* Perform exploratory testing on the DemoBlaze website.
* Identify functional and UI-related issues.
* Verify application behavior under valid and invalid conditions.
* Prepare detailed manual test cases.
* Document discovered bugs with reproducible steps.
* Validate the overall user experience across major modules.

## 🧩 Modules Tested

### 1. UI Testing

Tested various user interface elements and their behavior, including:

* Navigation and menus
* Buttons and links
* Product display
* Forms and input fields
* Page layout and consistency
* UI validation and error messages

### 2. Authentication Testing

Tested the application's authentication functionality, including:

* User Registration
* User Login
* Logout
* Valid credentials
* Invalid credentials
* Empty fields
* Incorrect username/password
* Duplicate user registration
* Input validation

### 3. Cart Testing

Tested the shopping cart functionality, including:

* Adding products to cart
* Removing products from cart
* Adding multiple products
* Cart item details
* Product quantity and price
* Cart total calculation
* Checkout/order placement
* Negative scenarios and invalid inputs
